`cargo test -p gdebug-module --test stock` runs a full debugger session on system libluajit (override `RSGDLL_LUAJIT`): Lua owner thread runs a loop calling a C `pump` (= `gdebug::dbg::think`), client thread drives over real loopback TCP. Not GMod qualification. Drive thread must set QUIT on panic or the Lua loop hangs forever. Unauthenticated non-hello request closes the connection after ERR_AUTH.
