For `editors/zed`, the Rust target is `wasm32-wasip2`, output `zed_gdebug.wasm`; Zed packages rename it to `extension.wasm` and include `extension.toml` plus `debug_adapter_schemas/`. The prebuilt manifest must include `[lib] kind = "Rust"` and `version` equal to the locked `zed_extension_api` version (currently 0.7.0), not the extension package version. Zed's own builder fills these fields; copying the source manifest alone does not. Sources: zed-industries/zed `crates/extension/src/extension_builder.rs`, `extension_manifest.rs`, and `crates/extension_cli/src/main.rs`.
