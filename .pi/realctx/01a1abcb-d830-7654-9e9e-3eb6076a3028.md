Cross builds need `RUSTFLAGS=""` (user's global rustflags use mold/--no-rosegment which zig and lld-link reject). Linux: `cargo zigbuild --release -p gdebug-module --features server|client --target i686-unknown-linux-gnu.2.17` (or x86_64-...2.17). Windows: `XWIN_ARCH=x86,x86_64 cargo xwin build --release -p gdebug-module --features server|client --target i686-pc-windows-msvc` (x86 SDK libs missing without XWIN_ARCH → kernel32.lib not found).
