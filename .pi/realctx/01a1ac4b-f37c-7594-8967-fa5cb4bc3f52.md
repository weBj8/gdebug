gdebug's build workflow uploads prepackaged assets with `actions/upload-artifact` and `archive: false`. The release workflow's `actions/download-artifact` must set `skip-decompress: true` alongside `merge-multiple: true`: otherwise `.zip` artifacts are automatically extracted (and Windows bundles may overwrite each other's gdebug.exe), while .tar.gz/.vsix remain raw. The release completeness check then fails because the Windows ZIP filenames are missing. Confirmed from publish logs and the v8.0.2 action inputs. Preserve same-run artifact selection and the six-file completeness check.
